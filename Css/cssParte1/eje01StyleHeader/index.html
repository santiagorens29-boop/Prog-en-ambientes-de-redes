Declaraciones de estilo definidas en el atributo de cada etiqueta 

    h1 {
    font-size: 1.8em; /* 1.8 veces el tamaño base del contenedor padre */
    color: #1a365d;
    text-align: left; /* Alineado a la izquierda */
    background-color: #e2e8f0;
    padding-left: 15px;
    border-left: 6px solid #2b6cb0;
    letter-spacing: 1px;
    }

Este texto tiene el estilo asignado individualmente mediante el atributo style.

La etiqueta h1 ocupa todo el ancho del contenedor (por default lleva display de bloque).

La etiqueta h1 lleva texto en color #1a365d con alineación hacia la izquierda.

El background de este h1 lleva un color de fondo gris azulado #e2e8f0.

El estilo definido incluye una barra lateral de acento y espaciado interno a la izquierda. 



    p {
    text-align: justify;
    font-size: 1.1em;
    color: #2d3748;
    font-style: italic;
    border-top-style: dashed;
    border-bottom-style: dashed;
    border-width: 1px;
    border-color: #718096;
    line-height: 1.6;
    }

Todos los textos con etiquetas p tienen su estilo definido dentro de su propio atributo style.

Para estos párrafos se define un estilo con estas características: Alineación justificada.

Tamaño de letra ligeramente mayor al base (1.1em) y tipografía de la familia Segoe UI.

Color de letra gris oscuro #2d3748 con interlineado ampliado.

Estilo de la fuente itálico para resaltar las descripciones.

Bordes superior e inferior discontinuos (dashed), finos y de color #718096.
